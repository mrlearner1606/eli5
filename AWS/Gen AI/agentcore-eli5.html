The idea

A brain in a jar can think. It can't do anything.

An LLM is like a genius new hire who shows up on day one with an amazing brain — and no hands, no notebook, no ID badge, and no workshop.

Ask it a question, it answers brilliantly. Ask it to actually book the flight, check your database, run the math, or remember yesterday's chat — and it just… can't. It can only text.

Worse: if you tried to build all of that yourself — the secure hosting, the tool plumbing, the memory store, the login system, the monitoring — you'd spend months on infrastructure before your agent does anything useful.

Amazon Bedrock AgentCore is AWS's answer: a set of ready-made, secure body parts for your agent. You bring the brain (any model, any framework); AgentCore provides the workshop, the hands, the memory, and the security cameras.

🧸 In one breath: AgentCore turns a chatbot that talks into an agent that acts — safely, at scale, without you managing servers.

The body parts

Seven modules. Each one fills a gap the brain can't fill alone.

🏭 the workshop floor

Runtime

The secure, serverless place your agent actually runs. It scales up and down on its own, and every user session gets its own isolated microVM — a sealed room, so sessions can't snoop on each other.

🧰 the toolbox adapter

Gateway

Takes your existing APIs, Lambda functions, and services — and turns them into MCP-compatible tools the agent can grab, in a few lines of code. No rewriting your backend.

📓 the notebook

Memory

Short-term memory keeps the current conversation coherent. Long-term memory persists across sessions — the agent remembers you next week, and you control what it keeps.

🎫 the ID badge

Identity

Proves who the agent is and what it's allowed to touch. Works with identity providers you already use — Cognito, Okta, Microsoft Entra ID, Auth0 — so users don't need new accounts.

🧮 the sealed math lab

Code Interpreter

An isolated sandbox where the agent can write and run code — Python, JavaScript, TypeScript — to do real math, crunch files, and verify its answers instead of guessing.

🌐 the web window

Browser

A fast, secure, cloud-hosted browser the agent can drive: navigate sites, fill forms, click buttons, extract info. Works with automation tools like Playwright — fully managed.

📺 the CCTV room

Observability

Traces every step the agent took — every thought, tool call, and output — using OpenTelemetry, viewable in CloudWatch. When an agent goes weird at 2 a.m., this is how you find out why.

🧸 Plain talk: Runtime hosts it, Gateway arms it, Memory keeps it, Identity vouches for it, Code Interpreter and Browser give it hands, Observability lets you watch it.

How it works

One user question, start to finish.

01
You ask the agent something hard. “Check our returns API and refund order #4521.”
⬇
02
Runtime spins up a sealed room. A microVM just for this session — your agent code plus any model you chose, isolated from everyone else's sessions.
⬇
03
Memory speaks up. “This user complained last Tuesday — be gentle.” Short-term context plus long-term recall lands in the prompt.
⬇
04
Identity shows the badge. The agent gets scoped, temporary credentials — only the permissions this task needs, nothing more.
⬇
05
Gateway hands over the tools. Your returns API — already wrapped as an MCP tool — gets called. If math is needed, Code Interpreter runs it; if a webpage matters, Browser reads it.
⬇
06
The refund happens — and CCTV caught all of it. Observability recorded every step as OTEL traces in CloudWatch, so you can audit exactly what the agent did.

🧸 Plain talk: ask → sealed room → memory → badge → tools → answer, with every step on camera.

On AWS

Where AgentCore fits in the AWS Gen AI world.

🤝 Amazon Bedrock

AgentCore lives under the Amazon Bedrock umbrella. Bedrock gives you the models (the brains); AgentCore gives you the agent infrastructure (the body). They're designed for each other but not locked together — AgentCore works with models outside Bedrock too.

🔌 MCP & A2A

AgentCore speaks the open protocols agents use: MCP (Model Context Protocol) for tools and A2A for agent-to-agent work. Gateway turns your APIs into MCP tools; your agent can also call remote MCP servers.

📊 Amazon CloudWatch

Observability emits standard OpenTelemetry traces that land in CloudWatch — same monitoring stack your other AWS workloads already use. No separate agent-only dashboard to learn.

🆚 The old way: Bedrock Agents

Bedrock also has the older, more opinionated Bedrock Agents service. AgentCore is the newer, more flexible sibling: bring any framework and model, get lower-level control. Simple flows → Bedrock Agents. Custom production agents → AgentCore.

🧸 Plain talk: Bedrock sells brains. AgentCore rents out the whole factory where brains become workers. CloudWatch watches the factory floor.
