LoRA, explained simply

LoRA means Low-Rank Adaptation. It is a clever way to teach an already-trained AI a new skill without rewriting all of its millions or billions of existing settings.

ELI5
One-liner

LoRA is like adding a small cheat-sheet to a giant textbook instead of rewriting the whole textbook. The original model stays mostly frozen; LoRA learns a small set of extra weights that steer the model toward the behavior you want.

Why does LoRA exist?
🏋️

Full fine-tuning is heavy

Changing every model weight can require lots of GPU memory, compute, storage, and training time.

🧩

Most weights don't need to move

For many tasks, you can get useful adaptation by learning a much smaller update rather than changing the whole model.

🎒

Adapters are portable

A LoRA adapter can be much smaller than a full copy of the adapted model, making it easier to store and swap between tasks.

The schoolbook analogy

📚 Base model

You already own a huge textbook containing years of knowledge. You don't want to rewrite every page.

📝 LoRA adapter

You add a small set of sticky notes that teach the textbook how to answer in a particular style or handle a particular task.

🔄 Swap adapters

Keep the same textbook, but use different sticky-note sets for coding, support conversations, medical terminology, or another specialized behavior.

How LoRA works
  1. 1
    Start with the trained model

    The original model weights are normally frozen during LoRA training.

  2. 2
    Add small trainable matrices

    LoRA represents the weight update using two much smaller matrices. Their product acts like a low-rank update to the original weight.

  3. 3
    Train only the adapter

    Your examples teach those small matrices how the model should change for the target task.

  4. 4
    Use base model + adapter

    At inference time, the model can use the learned adapter alongside the frozen base model. Depending on the tooling, the adapter can also be merged into the base weights.

Gotchas / fine print
LoRA is not a magic accuracy button

Bad examples, noisy labels, or a poor training objective can still produce poor results.

Rank matters

The LoRA rank controls the capacity of the adapter. Too little capacity may underfit; more capacity can increase memory and training cost.

LoRA is for adaptation, not a knowledge database

If the goal is to answer from frequently changing documents, RAG may be a better fit than trying to train every document into the model.

QLoRA is related, but not identical

QLoRA combines quantization of the base model with LoRA-style training. Don't treat the two names as interchangeable.

TL;DR
  • LoRA = Low-Rank Adaptation. It is a parameter-efficient fine-tuning technique.
  • Freeze the big model. Train a much smaller adapter instead of updating everything.
  • Think sticky notes, not a rewritten textbook.
  • Adapters can be swapped. One base model can support different specialized adaptations.
  • QLoRA adds quantization. It combines a quantized base model with LoRA training.
